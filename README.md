# D1 Desk Clock 

A Pico W powered smart(ish) desk clock.

![D1 Clock](images/D1-clock.jpg)

## Overview

D1 is a desk clock that can do more than just tell the time! It can show you the current weather, your room temperature, turn on/off your smartplugs, it even has faces!

Its PCB design uses breakout board connectors so that you can add or remove any modules you like (provided you modify the code). 

I am using the below breakout modules:

* **[MSA301 3DoF Motion Sensor](https://shop.pimoroni.com/products/msa301-3dof-motion-sensor-breakout)**
* **[RV3028 Real-Time Clock](https://shop.pimoroni.com/products/rv3028-real-time-clock-rtc-breakout?variant=27926940549203)**
* **[BME280 Temperature Sensor](https://shop.pimoroni.com/products/bme280-breakout?variant=29420960677971)**

## Features

* **Tell the time duhh**
* **Intergrates with openweatherapi to show the weather**
* **Interchangable breakout sensor modules**
* **Control smart switches via MQTT**
* **Show ambient temperature and humidity**
* **Emotions! If you pickup D1 they will be shocked by the sudden movement. They also get sleepy**
