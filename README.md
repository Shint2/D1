# D1 Desk Clock 

A Pico W powered smart(ish) desk clock.

![D1 Clock](images/D1-clock.jpg)

## Overview

D1 is a desk clock that can do more than just tell the time! It can show you the current weather, your room temperature, turn on/off your smartplugs, it even has faces!

Its PCB design uses breakout board connectors so that you can add or remove any modules you like (provided you modify the code). 

I am using the below breakout modules

* **MSA301 3DoF Motion Sensor**
* **RV3028 Real-Time Clock**
* **BME280 Temperature Sensor**
